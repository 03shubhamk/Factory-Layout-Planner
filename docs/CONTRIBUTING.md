# Contributing to Factory Layout Planner

Thank you for your interest in improving Factory Layout Planner!

## Workflow & Git Guidelines
1. Fork and create your feature branch: `git checkout -b feat/my-new-feature`
2. Write clean, self-documenting code with JSDoc / TypeScript comments.
3. Verify test runner: `node tests/test-runner.js`
4. Verify client builds: `npm run build --prefix client`
5. Commit using Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`, `chore:`).
6. Push to your branch and open a Pull Request.
